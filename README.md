The main purpose of this repository is to practice JavaScript concepts by applying them to small, real-world UI problems instead of only watching tutorials.

These projects help me understand how JavaScript works in the browser and how logic is applied to actual webpages.

I created this repository to:

- Learn how JavaScript controls UI behavior
